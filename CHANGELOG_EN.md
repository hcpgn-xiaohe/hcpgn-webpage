# Changelog

## V1.1.1 (2026-8-1)

### 🏗️ Architecture Refactor

- **Full migration to Vue 3**: Rebuilt from a pure vanilla-JS SPA into Vue 3 + Vite 6 + Vue Router 4 + vue-i18n 11
- **Component-based**: Split into single-file components such as Navbar, AppFooter, BannerSlider, NotificationCenter
- **Routing upgrade**: Adopted History mode, so the address bar no longer shows `/#/`; old paths (e.g. `/zh-cn/about/`) are automatically redirected to the new routes
- **Build optimization**: Code splitting (vue-vendor as a separate chunk), gzip total ≈ 67KB

### 🔄 Backend Data Update Mode

- Banner carousel, game list, AI page, and notifications are all switched to JSON data-driven
- Data files are organized by module under `public/data/` (banner / games / ai / notification each in its own folder, with images stored alongside the JSON)
- The data-fetching layer has a built-in in-memory cache (5-minute TTL), loading state, and error messages

### 🔔 New Notification System

- Navbar bell icon + red unread-count badge
- Dropdown panel: shows the latest 5 by default, with "Mark all as read" support
- Relative time display: just now / x minutes ago / x hours ago / x days ago; beyond 7 days shows the date
- Click a notification to open a detail popup showing the full date-time and body text
- New `/notifications` page listing all notifications in a card-style list
- Read state is stored locally in the browser (localStorage) and synced in real time across components and tabs
- Supports four types — info / update / warning / announcement — in both Chinese and English

### 🎨 UI Improvements

- **Language switch**: Changed to a globe icon button; clicking opens a popup to choose "中文 / English"
- **Navbar**: the Home, Games, AI, and About links are centered with wider spacing
- Fixed a missing-space issue in the English UI font description

### 🗂️ File System Cleanup

- Removed 20+ obsolete files (old SPA scripts, unused fonts and images, conflicting pages)
- Image classification: social icons moved to `images/social/`, module images moved to the corresponding `data/` subfolders
- Renamed the Chinese filename `人生已完成清单.png` to `life-checklist.png`
